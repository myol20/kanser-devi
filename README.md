# 🧠 Kanser Tahmin Projesi

**Hazırlayan:** Mustafa Yol / Mustafa Arslan

---

## 📌 Proje Amacı

Bu projede makine öğrenmesi algoritmaları kullanılarak hastalardan elde edilen veriler üzerinden **kanser teşhisi (iyi huylu / kötü huylu)** tahmini yapılmıştır.

Amaç, veriye dayalı olarak erken teşhise yardımcı olabilecek bir model geliştirmektir.

---

## 🛠️ Kullanılan Teknolojiler

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

---

## 📊 Kullanılan Yöntemler

Projede iki farklı makine öğrenmesi algoritması kullanılmıştır:

* Random Forest
* Logistic Regression

Veri:

* %80 eğitim
* %20 test

olarak ayrılmıştır ve standartlaştırma işlemi uygulanmıştır.

---

## 📈 Model Performansları

### 🔹 Random Forest

* Doğruluk (Accuracy): **%96**

### 🔹 Logistic Regression

* Doğruluk (Accuracy): **%98**

📌 En iyi performansı **Logistic Regression** modeli vermiştir.

---

## 📉 Görselleştirmeler

Projede aşağıdaki analizler yapılmıştır:

* Korelasyon ısı haritası
* Confusion Matrix (karmaşıklık matrisi)
* Özellik önem sıralaması (feature importance)
